## About teenBank
teenBank is a teens first mobile wallet, with distinct features serving teenagers to learn financial literacy and have a ledger for use with real money inside. it includes features which incorporates digital banking into their lives such as sending money via instagram handles, or snapchat usernames, instead of asking them for long and lengthy account numbers. Plus you can add labels and tags to transactions so that you can keep record of what you spent that money on.
it includes Ai summaries , ai based ledger management, and incorporation via MCPS

The idea is currently pre mature, i mean its currently all mock money and transactions, all features can be modified or re arragned if this project ever becomes a legal and real piece a shit.
